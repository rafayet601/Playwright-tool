# Hacker News Top 100 Scraper

Scrapes the top 100 posts from Hacker News, sorted by upvotes (points), using Playwright.

## Features

- Headless Chromium browser with Playwright
- Parses title, link, and score from each post
- Aggregates and sorts the top 100 posts

## Requirements

- Node.js 18+
- npm

## Install

```bash
npm install
```

## Run

```bash
npm run scrape
```

## Output

An array of top 100 Hacker News stories logged to the console.
